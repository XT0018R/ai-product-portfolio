荣誉
省级大学生创新创业训练计划
⚡ 痛点
高中生选专业时严重信息不对称——专业名称耳熟能详，但真实的学习内容、课程难度、就业方向全凭想象。我学建筑后发现"想象与现实差距巨大"，这种信息差导致大量学生选错专业、后悔四年。
✦ 方案
构建"可感可视化大学专业体验馆"："想象 vs 现实"对比卡让差距可感，六维雷达图让专业特征可视化，AI 虚拟学长让真实体验可对话。覆盖 21 个专业，每个有独立 AI 身份与知识库。
产品架构 · 三屏流程
01
首页 · 选专业
6 个热门专业快捷入口 + 6 大类 21 个专业卡片浏览，热门专业在大类中带"热"标记
02
详情 · 看专业
想象 vs 现实对比卡 + 六维雷达图 + 专业介绍 / 核心课程 / 日常学习 / 就业方向 / 考研指南
03
对话 · 问学长
AI 虚拟学长流式对话，每专业 5 个快捷问题，30 轮对话限制，Markdown 渲染
关键设计决策
⚡
"可感" — 想象 vs 现实
每个专业详情页顶部展示"你以为的"和"真实的"对比，让用户一眼感受差距。从"学建筑发现想象与现实差距大"的亲身经历出发。
📊
"可视化" — 六维雷达图
SVG 雷达图展示学习难度、就业前景、实践比重、考研难度、收入预期、自由度。不同专业形状截然不同。
🤖
Prompt 工程 — 独立 AI 身份
21 个专业各有独立 system prompt，AI 学长以该专业在读学生身份回答。每专业配 5 个高频快捷问题引导冷启动。
技术实现
01
放弃 Coze 平台，自建 DeepSeek API 方案
Coze 积分消耗过快不适合长期运行；改为 DeepSeek API + 纯 HTML 单页应用，零后端依赖，打开即用，成本可控。
02
API Key base64 嵌入，用户打开即用
目标用户（高中生及家长）打开链接即可体验，无需注册或输入 API Key。base64 编码避免明文暴露，配合 30 轮对话限制控制成本。
03
流式输出 + Markdown 渲染
SSE 实现流式输出，打字机效果提升感知速度；marked.js 实时渲染 Markdown，支持表格、列表、加粗。
