# 🎓 可感可视化大学专业体验馆 · AI 虚拟学长

> 省级大学生创新创业训练计划项目 · 21 个专业可对话式 AI 体验

🔗 在线 Demo：https://12c0bda130b64a6aa6cd44bd7fcd38bf.bj8.agentos-app.net/ai-senior-chatbot.html

## 一句话定位

一个让高三 / 大一新生"提前感知真实专业"的对话式 AI 体验馆：基于 21 个专业建立可对话的"虚拟学长"，缩小专业想象与现实的差距。

## 背景与痛点

"学建筑后发现专业想象与现实差距大"——专业认知偏差是大一新生退学 / 转专业的常见诱因。现有填志愿信息多为纸面介绍，缺乏"和真实在读/毕业的人聊聊感受"的渠道。

## 目标用户

高三毕业生与大一新生（及关心其选专业的家长），核心痛点：不了解专业的真实课程、就业与生活。

## 核心功能

- **21 个专业 + 6 大类 105 个快捷问题**：覆盖主要专业方向，预设高频疑问。
- **"想象 vs 现实"对比卡 + 六维雷达图**：把抽象的专业认知差异可视化。
- **对话式 AI（虚拟学长）**：每个专业独立 system prompt，模拟真实学长口吻。

## 技术架构（PM 视角）

- **Prompt 工程**：为 21 个专业各设计独立 system prompt，保证回答的专业性与口吻一致性。
- **DeepSeek API + SSE 流式输出**：逐字流式返回，配合 Markdown 渲染，对话感接近原生应用。
- **零后端依赖**：静态前端直接调 API，可独立部署、成本极低。

## 关键产品决策

- 用"对比卡 + 雷达图"而非纯问答，是因为**认知差异需要可视化**，文字问答难以让用户直观感受 "差距有多大"。
- 独立 system prompt 而非单一大 prompt，是为保证**每个专业都像"这个专业的学长"**，而非笼统的通用 AI。

## 成果与价值

获省级大创立项；作为 0→1 的完整 AI 产品案例，证明"产品方法论 + AI 落地能力可复用到不同垂直场景"。
