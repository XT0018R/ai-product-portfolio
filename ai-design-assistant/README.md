## 这个产品解决什么问题

传统建筑毕设需完成大量分析图与效果图——历史脉络、水文分析、人群使用场景、无障碍设计、建筑效果图、立面图、室内图……纯手工绘制每张需 3-5 天，全部完成需要数周，严重压缩设计思考时间。这个项目构建 **AI 辅助设计工作流**：前期用 AI 生成调研分析图，中期用 AI 辅助空间推演，后期用 AI 渲染效果图。人工负责设计决策，AI 负责执行渲染。

## 核心功能

- 前期调研 · 分析图生成：历史脉络、盘龙江水文、无障碍设计分析，喂原始数据给 AI，生成专业级分析图，效率提升 10 倍
- 空间推演 · 场景生成：12 个空间使用场景轴测图，AI 批量生成初版，人工微调确认
- 成果渲染 · 效果图输出：建筑外景、立面图、室内，Gemini 渲染质量稳定，色彩风格统一，达到毕设交付标准

## 为什么这样做（产品决策）

- **用户痛点 → 方案**：我观察到设计出图是"重复劳动挤压思考时间"的典型场景，因此选择「AI 辅助工作流」而非「AI 全自动」——人工负责设计决策，AI 负责执行渲染，把 AI 能力封装成可复用、可维护的设计流程。
- **取舍（工具协同）**：在「单工具」和「多工具协同」之间选择了后者——ChatGPT 负责分析图生成（逻辑推理强），Gemini 负责效果图渲染（视觉质量稳定），各取所长。
- **取舍（Prompt 封装）**：把每个设计环节的 prompt 沉淀为可复用模板，而不是一次性对话——这体现了"把 AI 能力产品化"的思维，好的 prompt 工程不只是会写提示词，而是能把提示词变成可复用、可维护的产品能力。
- **数据/验证**：传统流程总计约 20-28 天，AI 辅助流程压缩到 3-4 天，效率提升约 7 倍；17 张分析图 + 9 张效果图全部 AI 辅助完成。

## 技术架构

- 模型 / API：ChatGPT · Gemini · DeepSeek
- 关键能力：分析图生成 · 效果图渲染 · Prompt 封装 · AI 工作流设计
- 工作流：前期调研 → 空间推演 → 成果渲染
- 产出：17 张分析图 + 9 张效果图

## 如何运行

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（复制 .env.example 为 .env 并填写）
cp .env.example .env

# 3. 启动开发服务
npm run dev
```

## 环境变量

```env
# 服务端口
PORT=3000

# LLM API Key（请使用你自己的 Key，切勿提交真实值）
LLM_API_KEY=sk-xxxxxxxxxxxxxxxx

# LLM API 地址
LLM_API_BASE=https://api.example.com
```
