⚡ 痛点
华晨宇十年演唱会的「舞台形态 / 场次 / 歌单」散落各处、且常被误传（如把普通四面台说成"火星乐园 2.0 永久基地"）；粉丝想回顾某场找不到准确信息，想分享现场记忆也没有统一阵地。
✦ 方案
做一个「权威 + 可共创」的火星演唱会档案馆——既能查每场准确信息，又能由歌迷共同书写记忆（现场照片 + 火星小故事），形成 UGC 闭环。明确定位为「官方信息整合 + 个人回忆存放」，UGC 只是附加价值，不做成内容社区。

关键设计决策 · PM 视角
📌
定位纯粹
只收正式演唱会，剔除混入的 3 个特别活动，保证档案「权威感」而非大杂烩。
💡
照片 ≠ 记忆
为回忆墙加纯文字「火星小故事」条目，让记忆有温度、也降低 UGC 门槛。
🔎
数据准确 > 美观
逐场回查官方信源，纠正舞台形态误传（乐园 = 星环、四面台 = 四面台）。
🧹
体验风险前置
前端图片压缩（最长边 1000px / JPEG 0.68），避免本地存储溢出。
合规设计 · 面向公众的 UGC 产品底线
版权合规 素材仅收录华晨宇本人 / 工作室 / 官方账号，视觉全部由代码生成，不抓取任何第三方二创图片或视频。
地图合规 自带中国省界 SVG（含台湾省、港澳特区及南海诸岛九段线），不依赖外部地图服务，符合国家地图管理规范。
隐私治理 回忆默认仅存本机，共享为 opt-in；按设备 ID 精确删除，防止匿名用户删改他人内容。
